🌊 WaveProxy Command Reference
================================

1. Core Commands
----------------

waveproxy query <url>
    Query the proxy for a given URL.
    
    Output:
      Proxy address (with quotes)  -> "socks5://127.0.0.1:1080"
      Direct connection            -> None
    
    Example:
      waveproxy query github.com
      > "socks5://127.0.0.1:1080"


waveproxy commandreference
    Print the complete command reference file.

    Example:
      waveproxy commandreference


waveproxy -h, --help
    Show help information.

waveproxy -V, --version
    Show version number.

waveproxy -s, --silent
    Silent mode (output result only).

waveproxy -v, --verbose
    Verbose mode (output debug info).

waveproxy -f, --fail
    Exit with non-zero code on error.

waveproxy --help-all
    Show help for all three commands (waveproxy, proxydeploy, proxywrap).

waveproxy query <url> --once
    Apply once-only logic to this specific query.


2. Wrapper
----------

proxywrap <any command>
    Auto-inject proxy into any command.

proxywrap --help-all
    Show help for all three commands.


3. Configuration Management (proxydeploy)
-----------------------------------------

proxydeploy
    Show the current default config name.
    
    Example:
      proxydeploy
      > default


proxydeploy list [@name]
    View the content of a config file.
    
    Without @name : Show the default config (default)
    With @name    : Show the specified config
    
    Examples:
      proxydeploy list
      proxydeploy list @work
      proxydeploy list @nonexistent  -> None


proxydeploy edit [@name]
    Edit a config file using nano.
    
    Without @name : Edit the default config
    With @name    : Edit the specified config
    If file doesn't exist, it will be created automatically.
    
    Examples:
      proxydeploy edit
      proxydeploy edit @work


proxydeploy -h, --help
    Show help information.

proxydeploy --help-all
    Show help for all three commands.


proxydeploy run --change-to-default @new @old
    Switch the default config to another one.
    
    Parameters:
      @new  : The config name to set as default (must exist)
      @old  : The current default config name (for confirmation)
    
    What it does:
      1. Copies proxydeploy@new.txt to proxydeploy@default.txt
      2. Updates WAVEPROXY_CONFIG environment variable to @new
    
    Example:
      proxydeploy run --change-to-default @work @default


proxydeploy run --print-working-proxy
    Print the currently active proxy variable from the config.
    
    Example:
      proxydeploy run --print-working-proxy
      > home


proxydeploy run --print-default-proxy
    Print the default proxy variable from the config.
    
    Example:
      proxydeploy run --print-default-proxy
      > home


proxydeploy run --print-detailed-working-proxy
    Print detailed content of the current config.
    
    Example:
      proxydeploy run --print-detailed-working-proxy
      > ==== work ====
      > <content of work>
      >                                      ----working


proxydeploy run --print-detailed-default-proxy
    Print detailed content of the default config.
    
    Example:
      proxydeploy run --print-detailed-default-proxy
      > ==== default ====
      > <content of default>
      >                                      ----default


proxydeploy run --print-detailed-all-proxy
    Print detailed content of ALL configs.
    
    Example:
      proxydeploy run --print-detailed-all-proxy
      > ==== default ====
      > <content of default>
      >                                      ----default
      > 
      > ==== work ====
      > <content of work>
      >                                      ----working


proxydeploy run --print-all-proxy
    List all available configs with right-aligned markers.
    
    Example:
      proxydeploy run --print-all-proxy
      > default                   ----default
      > home
      > work                      ----working


proxydeploy run --create-new-proxy @name
    Create a new config file and open it with nano.
    If the file already exists, it opens it for editing.

    Example:
      proxydeploy run --create-new-proxy @project
      > (opens nano with proxydeploy@project.txt)


proxydeploy run --enforce-proxy @name [--once]
    Force WaveProxy to use a specific config.
    Without --once: stays active until terminal closes.
    With --once:    affects only the next query.

    Example:
      proxydeploy run --enforce-proxy @work
      > 🌊 Config 'work' enforced for current session.


proxydeploy run --enforce-proxy "proxy_url" [--once]
    Force WaveProxy to return a specific proxy address.
    Without --once: stays active until terminal closes.
    With --once:    affects only the next query.

    Example:
      proxydeploy run --enforce-proxy "socks5://127.0.0.1:1080"
      > 🌊 Proxy 'socks5://127.0.0.1:1080' enforced.


proxydeploy run --ignore-proxy @name [--once]
    Temporarily ignore a config file.
    Without --once: stays active until terminal closes.
    With --once:    affects only the next query.

    Example:
      proxydeploy run --ignore-proxy @work
      > 🌊 Config 'work' ignored.


proxydeploy run --ignore-proxy "proxy_url" [--once]
    Temporarily ignore a specific proxy address.
    Without --once: stays active until terminal closes.
    With --once:    affects only the next query.

    Example:
      proxydeploy run --ignore-proxy "socks5://127.0.0.1:1080"
      > 🌊 Proxy 'socks5://127.0.0.1:1080' ignored.


proxydeploy run --provisional-start
    Start provisional mode. All temporary settings (enforce/ignore) will remain
    active until you run --provisional-end or close the terminal.

    Example:
      proxydeploy run --provisional-start
      > 🌊 Provisional mode started.


proxydeploy run --provisional-end
    End provisional mode and clear all temporary settings.

    Example:
      proxydeploy run --provisional-end
      > 🌊 Provisional mode ended. All temporary settings cleared.


4. Environment Variable
-----------------------

WAVEPROXY_CONFIG
    Temporarily or permanently switch the active config.
    
    Temporary (single command):
      WAVEPROXY_CONFIG=work waveproxy query github.com
    
    Permanent (current session):
      export WAVEPROXY_CONFIG=work
      waveproxy query github.com
    
    Switch back to default:
      export WAVEPROXY_CONFIG=default


5. Installation & Uninstallation
--------------------------------

Install:
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Sha0huaZhang/WaveProxy/main/install.sh)"

Uninstall:
    /bin/bash -c "INSTALL_DIR=\"\$HOME/.local/waveproxy\"; echo -e \"\033[31mYou are deleting WaveProxy, are you sure? [Y/n]\033[0m\"; read -n 1 -r; echo; if [[ ! \$REPLY =~ ^[Yy]\$ ]]; then echo \"🌊 Uninstall cancelled.\"; exit 0; fi; if [ -d \"\$INSTALL_DIR\" ]; then echo \"🌊 Removing \$INSTALL_DIR...\"; rm -rf \"\$INSTALL_DIR\"; else echo \"🌊 WaveProxy installation directory not found. Skipping.\"; fi; for RC_FILE in \"\$HOME/.zshrc\" \"\$HOME/.bashrc\"; do if [ -f \"\$RC_FILE\" ]; then sed -i '' '/# WaveProxy/d' \"\$RC_FILE\" 2>/dev/null || true; sed -i '' '/export PATH=\".*waveproxy\/bin/d' \"\$RC_FILE\" 2>/dev/null || true; echo \"🌊 Removed WaveProxy PATH entries from \$RC_FILE\"; fi; done; echo \"\"; echo \"🌊 WaveProxy has been uninstalled.\"; echo \"🌊 Please restart your terminal to apply changes.\""

7. Default Configuration Example
--------------------------------

Below is the complete default configuration file that comes with WaveProxy.
You can use it as a template to create your own rules.

<!--
    WaveProxy default configuration file
    Location: ~/.local/waveproxy/proxydeploy@default.txt
    Edit with: proxydeploy edit
-->

def proxy:
    <!-- Define your proxy variables here -->
    let "home" = "socks5://127.0.0.1:1080"
    let "work" = "http://proxy.company.com:8080"

[proxy_rule:
    <!-- Rules using the "home" proxy -->
    "home":
        "github.com/**"
        "raw.githubusercontent.com/**"
        "api.github.com/**"
        ! "**.github.com/**" unless "https://github.com/**" "raw.githubusercontent.com/**" "api.github.com/**"
        ! "gitlab.internal.company.com"
        ! "mirrors.company.com"
        ! "**.local/**"

    <!-- Rules using the "work" proxy -->
    "work":
        "internal.company.com" direct
        ? "home"
        default: "home"
]
